# 经营排行接口对接说明

OA 经 `ops_reader` 消费订单开放层 v1.3 的 4.9、5.1 节。`GET /oa-api/orders/rankings` 接受 `group`、`sort`、`order`、`offset` 以及原有业务筛选。列与参数以 [OA OpenAPI](../api/oa-openapi.yaml) 为准。

| 榜 | 一行 | 展示规则 |
|---|---|---|
| 店铺 | 一个 shop_id | 默认按订单应付降序 |
| 宝贝 | 一个 shop_id 与 shop_item_id 组合 | 排好当前页后按双键左联 v_listings。展示当前标题，缺标题展示宝贝 ID。SKU 名称不参与宝贝名称和分组。 |
| 店铺 SKU | 一个店铺与 SKU 编码组合 | 同店下多个宝贝合并为同一行，保留分店视角。可按销售额或销量排序。 |
| 人员 | 一个 person_id | 限超级管理员。分页后关联 v_reg_person；缺姓名展示 ID，已归档照常显示并标记。人员销售额不能跨人直接相加。 |

平台榜和店铺增长榜沿用既有口径。没有排序参数时保留原降序和旧字段。排序指标按榜单列入白名单，方向只接受 `asc`、`desc`；未知值、空值或参数重复返回 400。可空指标升降序均置尾。内外层排序均以完整分组键收尾。结果包含总组数，每页最多 100 条。

相同数据快照下可逐页遍历。活跃期间若新销售改变排名，不同 HTTP 请求可能读取不同水位；跨请求的冻结快照不属于本接口能力。
