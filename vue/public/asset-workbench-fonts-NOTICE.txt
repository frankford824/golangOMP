Asset Workbench Font Notice

The asset workbench uses self-hosted fonts only. No runtime font CDN is used.

Fonts:
- Source Han Sans CN AW Core, generated from @fontpkg/source-han-sans-cn-vf 2.5.2, OFL-1.1, used for the asset workbench Chinese UI subset.
- Source Han Sans CN VF Fallback, package @fontpkg/source-han-sans-cn-vf 2.5.2, OFL-1.1, used for CJK glyphs outside the UI subset.
- Geist Sans, package @fontsource/geist-sans 5.2.5, OFL-1.1, used for Latin UI text.
- Geist Mono, package @fontsource/geist-mono 5.2.8, OFL-1.1, used for numbers, IDs, money, hashes, and dates.

Full license texts are included in the corresponding npm packages in the source distribution.
Missing CJK glyphs fall back to Source Han Sans CN VF Fallback first, then system CJK fonts.
